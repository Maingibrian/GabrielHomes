1 · Executive verdict

Keep the fonts. Fix the details. That is what shipped.

The r15 audit measured the existing type system — self-hosted variable Geist (UI/body), Fraunces (display serif), Geist Mono (labels/data) — at a weighted 8.7 / 10 (87%) against the fixed rubric in §4. Three credible alternative families scored lower on the same rubric (ESTIMATE), because they trade away the site's brand character for gains the measurements did not support. Per the selection rule — switch only on meaningful measured improvement — no alternative cleared the bar. Instead r15 shipped 50+ targeted fixes to the weak spots the audit measured (mono tracking, sub-floor sizes, line measure, missing preloads), all centralized in the existing token system, and re-validated with rendered evidence (§7). Full test suite: 381 / 381 green.

3 · Font-size audit — hierarchy, floors, small text

  • Public pages: a DOM-wide walk found no text below 13px on any public page — the token floor --text-xs holds everywhere.
  • Violations of the site's own floor (fixed in r15): dashboard badges/labels rendered at 10px (2 spots → moved to --text-xs = 13px) and admin panels used 12–12.8px (0.8rem / 0.75rem → raised to 0.8125rem = 13px).
  • Hierarchy: the desktop ladder 16 → 18/20 → 24/28 → 36 → 64 → 80 gives clear 1.25–1.5× steps; every level is distinct — no ambiguous neighbours. Judged PASS.
  • Long-form measure: the audit's worst readability finding — .story__body set 58ch but rendered 84–98 real characters per line (ch units measure the "0" glyph; real prose runs wider), and .prose rendered ≈ 100 cpl. Comfortable reading range is 45–75 cpl.

5 · Selection decision

Decision: retain Geist + Fraunces + Geist Mono; fix the measured weaknesses in place.

Rationale in three lines: (1) every observed deduction was fixable without touching font files — tracking, sizes, measure, preloads are pure CSS; (2) any family swap is a brand decision that the measurements did not justify; (3) keeping the families keeps the risk surface to CSS-only changes, which the 381-test suite and rendered validation cover end-to-end.

8 · Remaining issues (honest ledger)

  • .prose leading is 1.3, not 1.65. The new --leading-prose token was applied to the home-page story block; docs-style .prose pages still use --leading-body (measured 20.8px @16px = 1.3). Compliant with 1.4.12 but tighter than ideal for long reading — candidate for r16: point .prose p/li at --leading-prose.
  • Alternative scores are expert estimates. The rubric was measured for the incumbent; the three alternatives were scored analytically (labelled above). A measured A/B would require temporarily shipping each family — judged not worth the churn given the decision.
  • Admin sits at the 13px floor. Compliant with the site's own floor, but dashboards are dense; if the admin grows, consider a dedicated --text-sm-plus token.
  • Ultra-wide behaviour not screenshot-verified. Fluid clamps were verified at 390/720/1024/1440; ≥2560px widths were reasoning-checked only.
  • Before-shots lost to the sandbox rollback. The pre-fix screenshots were wiped in the 2026-10-19 rollback; after-shots + validation JSON were regenerated from the live site the same day.
