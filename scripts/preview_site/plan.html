01Where we stand

The audit's headline: this is not a 60%-done project. The application layer is finished and regression-gated. What remains is deployment, content, four polish items, and handoff.

Already built & verified

  • Full page set: home, search + filters (price/beds/type/location/amenities/sort), listing detail (gallery, agent card, WhatsApp, JSON-LD, similar listings), agents directory + profiles, about, contact, privacy, terms
  • Inquiry pipeline: HTMX form, honeypot, 3/min rate limit, agent email templating, status tracking (new/read/replied)
  • Agent dashboard: create/edit listings, image manager, inquiry inbox — role-gated (is_agent + AgencyProfile)
  • Auth: allauth email login/signup, saved properties, admin fully tuned (inlines, slugs, actions)
  • SEO: sitemap.xml, robots.txt, OG/Twitter blocks, JSON-LD on detail
  • Deploy readiness: split settings (base/dev/prod), DEPLOY.md runbook, WhiteNoise + gunicorn pinned, security headers configured

Standing between us and the demo

  • Not deployed: no domain, host, SSL or transactional email yet
  • Workspace DB not initialized this session (migrate + seed needed; 287 property images sitting at project root from a past MEDIA_ROOT override — must be normalized)
  • Allauth login/signup pages are unthemed — the only off-brand surface a client would see
  • Contact page is info-only — no form (model already supports general inquiries)
  • Real client content pending: listings, agency profiles, WhatsApp number
  • No backups; no Lighthouse/device QA pass on prod
