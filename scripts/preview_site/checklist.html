1. Where We Stand

The site is feature-complete: search & filters, listing pages with map + JSON-LD, the enquiry pipeline (rate limit + honeypot + email), agent dashboards, saved listings, admin, sitemap and social cards — all tested. What stood between it and launch were production-grade gaps: security hardening, deploy plumbing, content provenance, operations. Those are now tracked in docs/PLAN.md with an automated gate.

Today's run closed the foundation plus six security blockers: git baseline with green gate · listing-title XSS closed · rate limiting ignores forged X-Forwarded-For and is shared across workers · demo passwords can never reach prod · prod refuses unsafe config (secret key, hosts, Postgres URL) · hashed static files now actually active. 2. What Remains on My Side (≈ 24 h engineering)

2.1 Finish security hardening

S7 — Upgrade to Django 5.2 LTS ~2 h

5.1 is past its security window; bump the pin, run the gate, fix fallout.

S8 — Dependency vulnerability audit ~0.5 h

pip-audit over pinned requirements; upgrade anything with a known CVE.

S9 — Never lose an enquiry silently ~2 h

Failed enquiry emails vanish today; add sent-at/error fields + a red "email not delivered" badge in the agent dashboard.

S10 — Security headers + self-hosted map ~2.5 h

Download Leaflet off unpkg into the repo, add a strict Content-Security-Policy, move inline scripts out of templates.

S11 — Template & XSS audit ~1 h

Every |safe / mark_safe / innerHTML usage gets a written verdict; user-influenced ones get fixed.

S12 — Input length caps ~1 h

Tested size limits on enquiry and listing fields; oversized junk rejected at the form.

2.2 Platform, deploy and data

D2 — Full test run on PostgreSQL ~1.5 h

258 tests currently run on SQLite; run them on real Postgres and fix dialect quirks.

D3 — /healthz/ + logging ~1 h

200 when the DB is reachable, 503 when not — the hook your uptime monitor needs; logs to stdout.

D4 — Correct the deploy runbook ~2 h

No demo seeding in prod, createcachetable, nginx real-IP header, gunicorn timeout, every .env key documented.

D5 — Backups + real restore drill ~2 h

Nightly pg_dump (30-day retention) plus a drill that proves a backup restores. An unrestored backup is a hope, not a backup.

D6 — make gate ~0.25 h

One command for every quality check.

C1 — Media cleanup ~1 h

List unused/junk images; archive after your OK; test guarantees every listing photo is referenced.

C2 — Production starts empty ~0.5 h

seed_demo refuses to run on the live server; fictional listings can never appear.

C3 — Enquiry retention ~1 h

Purge command (365 days suggested, your call) + cron — supports deletion requests.

2.3 Verification & launch rehearsal

V1 — Coverage ≥ 80% ~1.5 h

On listings/agents/inquiries, wired into the gate so it can't rot.

V2 — Browser QA at 360/810/1280 px ~1 h

Screenshots of home, search, detail, enquiry, dashboard against the owner QA list.

V3 — Load smoke ~0.5 h

20 concurrent users for 60 s on staging; zero errors, p95 < 500 ms on the 2 GB VPS.

R1–R2 — Fresh-server rehearsal + smoke script ~3 h

Follow DEPLOY.md word-for-word on a clean VM, fix every deviation in the doc, confirm HTTPS + /healthz/. Launch becomes a replay.
