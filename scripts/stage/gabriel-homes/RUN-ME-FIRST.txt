================================================================
  GABRIEL HOMES — READ ME FIRST (one-click local website)
================================================================

WHAT IS THIS?
  The complete Gabriel Homes property-listings website (Django).
  Double-click ONE file and the whole site runs on your computer:

    Windows :  START-GABRIEL-HOMES.bat
    macOS   :  START-GABRIEL-HOMES.command
    Linux   :  START-GABRIEL-HOMES.sh

  The launcher automatically:
    - installs Python (if missing) and the project dependencies
    - creates the database and loads ~80 demo Kenyan property
      listings, agents and images (first run only)
    - opens your browser at the site


WHAT YOU NEED
  - Any modern computer (Windows 10/11, macOS 12+, or Linux)
  - Internet connection on the FIRST run only (1-3 minutes of
    downloading). After that, the site runs fully offline.


HOW TO START
  WINDOWS
    1. Double-click  START-GABRIEL-HOMES.bat
    2. Wait for the console to finish its first-run setup
    3. Your browser opens the site automatically

  macOS
    1. Double-click  START-GABRIEL-HOMES.command
       - If macOS says the file "cannot be opened because it is
         from an unidentified developer": right-click the file
         and choose "Open", then confirm "Open".
       - If it says "Permission denied": open Terminal, drag the
         file in, and run once:
           chmod +x START-GABRIEL-HOMES.command
    2. Your browser opens the site automatically

  LINUX
    1. In a terminal, from this folder:
         chmod +x START-GABRIEL-HOMES.sh
         ./START-GABRIEL-HOMES.sh
       (many file managers also let you double-click it)
    2. Your browser opens the site automatically

                                             in the console window)

                     admin@gabrielhomes.co.ke / gabriel2026

                     hello@gabrielhomes.co.ke / gabriel2026

  NOTE: if port 8000 was busy, the launcher picks the next free
  port (8001, 8002, ...) — always use the URL printed in the
  console window.


HOW TO STOP
  - Simply close the launcher's console/terminal window, OR
  - run  STOP-WEBSITE.bat  (Windows)  /  STOP-WEBSITE.sh  (macOS+Linux)


WHERE IS MY DATA?
  - Everything lives inside this folder:
      db.sqlite3          the database (all listings, enquiries, users)
      property-images/    listing images
  - To reset to a factory-fresh demo: stop the site, delete
    db.sqlite3 (and optionally property-images/), then start again.
  - To back up: copy those two items somewhere safe.


TROUBLESHOOTING
  - "Python was not found" / installer did not run:
      Install Python 3.12 from https://www.python.org/downloads/
      (Windows: tick "Add python.exe to PATH"), then start again.
  - Port already in use:
      The launcher automatically uses the next free port — check
      the URL it prints. To free port 8000, run the STOP script.
  - Dependency install failed:
      Check your internet connection and start again. To force a
      reinstall, delete the .venv folder.
  - Images missing after a fresh seed:
      They regenerate automatically — give it a few seconds and
      refresh the browser.
  - macOS blocks the .command file:
      Right-click -> Open, or remove the quarantine flag:
      xattr -d com.apple.quarantine START-GABRIEL-HOMES.command
